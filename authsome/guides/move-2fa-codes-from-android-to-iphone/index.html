How to Move 2FA Codes From Android to iPhone

It depends on the app you use on Android. Google Authenticator brings synced 2FA codes across when you sign in, Aegis and 2FAS move by a backup file that you export on Android and import on the iPhone, and Microsoft Authenticator has to be set up again. Keep the Android phone until every 2FA code works on the iPhone.

What Moves and What Does Not

Two factor authentication, or 2FA, is the short code a service asks for after your password. An authenticator app makes each 2FA code from a secret key, which the service gives it inside a QR code when you turn on 2FA. Apple calls it a setup key, and AuthSome calls it a Secret. Moving to an iPhone means moving those secret keys. This guide calls the line in an authenticator app for one service an entry. Makers call it an account, a token or a code, and AuthSome calls it an Account.

The route to iPhone for each Android authenticator app
App on AndroidRoute to iPhone
Google AuthenticatorSign in to Google, or use the export QR code
AegisExport a file, import it into another app
2FASExport a file, import it on the iPhone
Microsoft AuthenticatorSet up each service again

Google says that if your 2FA codes are saved to your Google Account, they arrive when you sign in to that account in Google Authenticator on the new phone. To leave Google Authenticator as well, see how to export Google Authenticator to another app.

Aegis has no iPhone app, and its developers say they have no plans to bring it to other platforms. So an Aegis user also has to choose a new app. 2FAS has an iPhone app, but its cloud backup uses Google Drive on Android and iCloud on iPhone, and 2FAS gives the backup file as the way across.

Microsoft says its backup only restores on the same type of device, so each service has to be set up again. For Authy, see what its maker says in Do Authenticator Apps Transfer to a New iPhone?

Export Your Entries From Aegis

The Aegis FAQ explains what an export is, but it does not list the steps. The steps below are read from the source code of version 3.4.3, released in September 2026. Aegis is open source, so its developers publish the exact wording of every screen, and the names below are copied from there. If your version looks different, look in its settings for the word Export.

  1. Open Aegis on the Android phone and open Settings.
  2. Choose Import & Export, then Export.
  3. Under Export format, choose the Aegis one, which makes a JSON file.
  4. Make sure Encrypt the vault is ticked.
  5. Save the file somewhere you can find it again.

The Aegis FAQ says the file is protected by the same password as your Aegis vault, which is why Aegis does not ask you to choose one. The app also has a setting in Security for a separate export password. If you turned that on, that is the password you will need on the iPhone.

You can untick Encrypt the vault, but Aegis warns against it and asks you to accept the risk. Only do that if the app you are moving to cannot read the encrypted file.

The Import & Export screen also has Export for Google Authenticator. It shows QR codes in the format Google Authenticator uses, for an app that imports those instead of files. Aegis says it leaves out any entry that does not use SHA1 and 6 digit 2FA codes, so count what arrives.

Export Your Entries From 2FAS

Decide about the password before you export. 2FAS recommends exporting with one. Its tutorial says the file ends in .2fas, that a password makes it unreadable in a text editor, and that without one everything in it can be read, the secret keys included. Anyone who gets a file with no password can make your 2FA codes.

If you are staying with 2FAS on the iPhone, use a password. AuthSome reads only a 2FAS backup with no password. For any other app, check its help pages before you export.

These steps are from the 2FAS support page on moving between iPhone and Android.

  1. Open 2FAS on the Android phone and open its settings or menu.
  2. Choose 2FAS Backup.
  3. Tap Export.
  4. Set the password, or leave it out if the new app needs that, then save the file on the phone.

Get the File to the iPhone

Aegis does not say how to move the file. 2FAS says only that you can save its backup to a USB stick or a computer. Any way of moving a file works, but the file holds your secret keys, so choose with care.

  • By cable through a computer. Copy the file from the Android phone to a computer you own, then on to the iPhone. Nothing is sent over the internet.
  • Through a storage service you already use on both phones. Upload it on Android, then save it into the Files app on the iPhone. Never do this with a file that has no password.
  • By email to yourself. A copy stays in your mailbox until you delete it. Never email a file that has no password.

However you move it, delete every copy once the import has worked. That means the copy on the Android phone, on the computer, in the storage service and in the Files app, and any email it was attached to.

Import the File on the iPhone

Use an app that says on its own pages that it reads your file.

  • 2FAS. Open its settings or menu, choose 2FAS Backup, then tap Import. Its tutorial also lists Aegis under Import Tokens, without saying on which phones, so check that the iPhone app shows it.
  • Proton Authenticator. Proton lists Aegis and 2FAS among the apps it imports from. Open Settings, choose Import and pick the app, and it shows the steps. Check there whether it wants the file with or without a password before you export.
  • AuthSome. Coming soon to the App Store, for iOS 26 or later. Tap +, then Import Accounts, then Choose a Backup File.

AuthSome reads an Aegis file whether it is encrypted or not, so leave Encrypt the vault ticked and type your Aegis password when asked. It does not read a 2FAS backup that has a password. A 2FAS backup has to be exported without a password, and AuthSome tells you so if you choose a protected one. That goes against what 2FAS recommends, and the file shows every secret key as plain text, so move it by cable and delete every copy as soon as the import has worked. In AuthSome you choose the Profile, and you see everything that was found before anything is added. An Account that cannot be imported is listed with the reason.

AuthSome has no Android app, and it cannot import from Microsoft Authenticator or Authy.

Check Everything Before You Wipe the Android Phone

Do not reset, sell or trade in the Android phone yet. Until you have checked the iPhone, the Android phone is your only proven way in.

  1. Count the entries on both phones. The numbers should match.
  2. Open the same entry on both phones at the same moment. The two 2FA codes should be the same number.
  3. Sign in to your most important services using the iPhone, starting with your email.
  4. Set up again any entry that did not come across. With a recovery code to hand, sign in to that service, turn 2FA off and on, and scan the new QR code with the iPhone.
  5. Delete every copy of the backup file.

The entries keep working on the Android phone after the move, because both phones now hold the same secret keys. Using the same authenticator app on two devices explains why. Before the Android phone leaves your hands, remove the entries from it or erase it. If you are also setting up the iPhone from an older iPhone, read whether authenticator apps transfer to a new iPhone.

Common Questions

Is There an Aegis Authenticator for iPhone?

No. Aegis is an Android app, and its FAQ says there are no plans to port it. On an iPhone you need a different authenticator app that can import an Aegis export.

Does 2FAS Sync Between Android and iPhone?

2FAS says its cloud sync works within one operating system, with Google Drive on Android and iCloud on iPhone. The way it gives for crossing between them is the backup file.

Can You Move Microsoft Authenticator From Android to iPhone?

Not with its backup. Microsoft says a backup restores only on the same type of device, and that one made on an iPhone cannot be restored on Android. Sign in to each service and add the iPhone as a new authenticator there.

Can You Transfer 2FA Codes Without the Old Android Phone?

Only if you already have a backup file or a cloud backup from it. Otherwise use the recovery codes each service gave you when you turned 2FA on, or ask the service to help you prove who you are.
