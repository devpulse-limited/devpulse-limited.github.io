Can You Use the Same Authenticator App on Two Devices?

Yes, for the standard 2FA codes that most services use. Either use an authenticator app that syncs your 2FA codes between your devices, or scan the same QR code on both devices when you turn on 2FA for a service. Both devices then show the same 2FA code at the same moment, and either one will sign you in. Apps registered with an employer are the main exception.

By Junaid Younus at DevPulse. Published 19 November 2026. Facts last checked 19 November 2026.

Why Two Devices Can Show the Same 2FA Code

Two factor authentication, or 2FA, adds a short code after your password. An authenticator app makes each 2FA code from a secret key, which the service gives it inside a QR code when you turn on 2FA. Apple calls it a setup key, and AuthSome calls it a Secret. The standard behind most authenticator apps works out each 2FA code from the secret key and the current time, and nothing else. Any device that holds the secret key and has the right time shows the same 2FA code.

A 2FA code carries nothing about the device that made it, so the service cannot tell two devices apart or count them. The two devices do not even need the same app.

Use an App That Syncs

A syncing app copies each secret key to your other devices for you, including the ones you add later. This is what each maker says about its own app.

Some details from those makers are worth knowing.

  • Google says that deleting a 2FA code that is synced removes it from every device, and that choosing Use Authenticator without an account keeps your 2FA codes on one device only.
  • 2FAS says its sync works between devices of the same kind, so between two iPhones, but not between an iPhone and an Android phone.
  • Ente says its synced 2FA codes can also be opened on the web at auth.ente.com.
  • Microsoft describes a backup that you restore, not a sync, and its backup page does not say whether both phones can then be used side by side.

Or Add the Same QR Code to Both Devices

This works with any authenticator app that makes standard 2FA codes, on any mix of devices, and needs no cloud account. Do it while the service is still showing the QR code.

  1. In the security settings of the service, turn on 2FA and choose the authenticator app option. It shows a QR code, and usually the secret key as a line of letters and numbers too.
  2. Scan the QR code with the first device. Do not type the 2FA code into the service yet.
  3. Scan the same QR code with the second device. If that device cannot scan, type the secret key in by hand.
  4. Check that both devices show the same 2FA code.
  5. Type that 2FA code into the service to finish, and save the recovery codes it offers.

Each device now holds its own copy. Nothing syncs, so renaming or deleting on one device changes nothing on the other. Do not keep a photo or screenshot of the QR code, because anyone who has it can make your 2FA codes.

What to Do for a Service You Already Set Up

The QR code is long gone, so you have three options. Try them in this order. The third one can lock you out if it goes wrong. A new QR code holds a new secret key, and the old 2FA codes for that service stop working once you confirm it.

This guide calls the line in an authenticator app for one service an entry. Makers call it an account, a token or a code, and AuthSome calls it an Account. Have a recovery code ready, do one service at a time, and delete the old entry only after a new 2FA code has signed you in.

  1. Turn on sync in the app you already use. If it is in the table above, the entry then appears on your other device.
  2. Show the secret key again. Look in the details of the entry for an option to show its QR code or secret key, and scan that with the second device. Not every app has one.
  3. Set up 2FA again at the service. Sign in, find the option to change or reset the authenticator app, and scan the new QR code with both devices before you confirm.

If you are replacing a phone and not adding one, see whether authenticator apps transfer to a new iPhone.

When Does This Not Work?

An app that your employer registers for you can hold more than a secret key, and what it holds may not copy to a second device.

  • Microsoft says the sign in details of a work or school account are not backed up from Microsoft Authenticator, and that the account has to be registered again on another device.
  • Duo says a work account in Duo Mobile can be restored on another phone only if the administrator has turned on its Duo Restore feature, and otherwise to contact your IT help desk.

For an app like these, ask your IT team how to add a second device.

Is It Less Safe on Two Devices?

In principle, a little, and you have to weigh that against the gain. The gain is that if one device is lost, broken or stolen, the other still signs you in, and you are not left hunting for recovery codes.

The cost is that there are now two places your secret keys can be taken from. Keep both devices behind a passcode, and erase a device before you sell it or hand it on.

Sync adds one more thing to protect, the cloud account that carries the secret keys. Read what the maker says about that. Google says it encrypts 2FA codes in transit and at rest. Ente says its sync is end to end encrypted, so its servers cannot read your 2FA codes. Whichever you choose, give that cloud account a strong password, and keep its recovery codes somewhere outside the authenticator app.

Common Questions

Can I Scan the Same QR Code Twice?

Yes, as long as the service is still showing it. The QR code holds the secret key, and every device that scans it makes the same 2FA codes. A service may not show it again once setup is finished, so scan with both devices before you close the page.

Can I Have the Same 2FA Codes on My iPhone, iPad and Mac?

Yes. Apple says the verification codes in Passwords, its name for 2FA codes, can be used on all your devices signed in to the same Apple Account with Passwords & Keychain turned on in iCloud settings. Google Authenticator and Ente Auth sync an iPhone and an iPad through their own accounts, and Ente Auth has a Mac app too.

Does Removing an Account From One Device Remove It From the Other?

With Google Authenticator synced to a Google Account, yes. Google says the deletion reaches every synced device, and you should expect the same from any app that syncs. If you scanned the same QR code on each device, no, each copy is separate and you remove it from each one.
